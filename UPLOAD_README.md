# Mark Ramirez Portfolio — Upload Package

This archive contains the editable source code and public assets for the portfolio website.

## Included

- Application source and styling
- OmniTimer artwork and public site assets
- Digital Resonance Theory PDF
- System Philosophy Framework PDF and DOCX
- Dependency lockfile and build configuration
- Hosting worker and validation scripts

## Not included

- `node_modules`
- Build output and caches
- Git history
- Existing deployment metadata
- Credentials or private runtime configuration

## Local setup

```bash
npm ci
npm run build
```

Use the hosting provider's Node/JavaScript project workflow and keep `package-lock.json` with `package.json`.
